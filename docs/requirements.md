# Жоба талаптары

## Пәндік сала
Университетте кабинеттердің кілттерін күзет пунктінде беру және қабылдау. **Сабақ кестесі модулі жоқ**; кабинетке қолжетімділік оқытушының белсенді тіркеуі, кілттің бос болуы, күзетшінің растауы арқылы бақыланады.

## Функционалдық талаптар
- FR-01. Оқытушы, күзетші, әкімшілік өкілі, жүйе әкімшісінің тіркелгі деректері сақталады.
- FR-02. Кабинеттер мен олардың кілттері тіркеледі.
- FR-03. Белсенді оқытушыға бос кілтті тек белсенді күзетші береді.
- FR-04. Бір кілтке бір мезгілде бірден артық ашық беру жазбасы болмайды.
- FR-05. Қайтаруды күзетші растайды; уақыт пен жауапты тұлға сақталады.
- FR-06. Әкімшілік ағымдағы күй мен беру/қайтару тарихын сұраумен көреді.
- FR-07. Жүйе әрекеттерін `key_audit` журналында тіркейді.

## Функционалдық емес талаптар
- NFR-01. СУБД — Microsoft SQL Server (T-SQL), іске қосу құралы — SSMS.
- NFR-02. Бір операция бірнеше DML өзгерісін транзакцияда орындайды.
- NFR-03. `UPDLOCK/HOLDLOCK`, `UNIQUE` filtered index екі рет беруді тежеуге арналған.
- NFR-04. `FOREIGN KEY`, `CHECK`, `UNIQUE` байланыстардың тұтастығын бақылайды.
- NFR-05. Git және GitHub нұсқаларды басқару құралы болады.
- NFR-06. Бұл оқу деңгейіндегі SQL-прототип; веб-интерфейс кейінгі кезеңге қалдырылған.
