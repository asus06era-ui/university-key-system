# SSMS-тағы тест сценарийлері

**Алғышарт:** 00_schema, 01_seed және 02_procedures орындалған, KEY-A-101 `available` күйінде.

| Код | Әрекет | Күтілетін нәтиже |
| --- | --- | --- |
| TC-01 | Белсенді оқытушыға кілт беру | `issued`, жаңа ашық key_issues және audit |
| TC-02 | Кілт беріліп тұрған кезде қайта беру | Қате №50002, екінші ашық жазба жоқ |
| TC-03 | Сол кілтті күзетшіге қайтару | `available`, `returned_at` толған |
| TC-04 | Бос кілтті қайта қайтару | Қате №50012 |
| TC-05 | Күзетшінің орнына әкімшілік ID жіберу | Қате №50004 немесе №50013 |
| TC-06 | Тарихты қарау (`v_issuance_history`) | Беру/қайтару уақыттары шығады |

**Орындау:** `sql/03_demo.sql` оң тесттерді өздігінен атқарады. Теріс тесттер үшін алдымен кілтті беріп, қайтармай тұрып қайта беру процедурасын жеке терезеде іске қосыңыз; содан соң қайтаруды орындаңыз. Басқа қате сценарийлерді де бөлек орындаңыз.

**Маңызды:** мұнда тек күтілетін нәтижелер көрсетілген. Нақты SSMS орындалуын студент өз серверінде тексеріп, скриншот жасайды.
