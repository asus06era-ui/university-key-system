# Пайдалану сценарийлері (Use Case)

## Қатысушылар
- **Оқытушы:** жеке тіркеуі арқылы кілт сұрайды және оны кері өткізеді.
- **Күзетші:** оқытушыны сәйкестендіреді, SQL процедурасы арқылы беруді/қайтаруды рәсімдейді.
- **Әкімшілік өкілі:** кілттердің ағымдағы жағдайын және тарихын қарайды.
- **Жүйе әкімшісі:** персонал мен кабинет туралы анықтамалық деректерді басқарады.

## UC-01. Кілтті тіркеу
Жүйе әкімшісі бөлмені және оның жалғыз негізгі кілтін `rooms`, `room_keys` объектілеріне енгізеді.

## UC-02. Кілттің бос екенін тексеру
Күзетші `room_keys.status` арқылы кілттің `available` күйінде екенін анықтайды.

## UC-03. Кілтті беру
1. Оқытушы тіркеу кодын ұсынады.
2. Күзетші `EXEC dbo.sp_issue_key` процедурасын шақырады.
3. Процедура оқытушы мен күзетшінің рөлін, белсенділігін және бос кілтті тексереді.
4. Транзакция `key_issues` жазбасын қосады, кілтті `issued` күйіне ауыстырады, аудит жасайды.
5. Кілт бос болмаса немесе рөл дұрыс болмаса — операция тоқтайды, транзакция қайтарылады.

## UC-04. Кілтті қайтару
Күзетші `EXEC dbo.sp_return_key` шақырады: ашық жазба жабылады, кілт `available` болады, аудит қосылады.

## UC-05. Есептер
Әкімшілік `dbo.v_key_status`, `dbo.v_issuance_history` көріністерін сұрайды.

**Сабақ кестесін тексеру бұл жобаға кірмейді.**
